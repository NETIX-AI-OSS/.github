# .github — NETIX.AI OSS Default Community Files

This repository contains the **default community health files** and the **organization profile landing page** for [NETIX-AI-OSS](https://github.com/NETIX-AI-OSS).

## Contents

| File / Folder | Purpose |
|---|---|
| [`profile/README.md`](profile/README.md) | Organization GitHub profile landing page |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | Default contribution guidelines (applies to all repos) |
| [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) | Default code of conduct (applies to all repos) |
| [`SECURITY.md`](SECURITY.md) | Default security policy (applies to all repos) |

Files placed here are automatically used by all repositories in the organization that do not provide their own versions. See [GitHub documentation](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file) for more details.
